{% load custom_tags %} {% comment %} Reusable representation switcher for List / Gallery / Map. These are true peer representations of the SAME dataset, so they belong in one segmented control. The Explorer (module dashboard) is a different navigation level and is deliberately NOT part of this switcher. Expected context: - representation_mode: 'list' | 'gallery' | 'map' | anything else (e.g. 'detail') Determines which segment is marked active. On detail pages pass a value that matches none (e.g. 'detail') so no segment is active. - list_type: 'published' | 'private' | 'review' (active scope; defaults to published) - public_url / private_url / review_url: list-view base URLs - public_gallery_url / private_gallery_url / review_gallery_url: gallery base URLs - public_map_url / private_map_url / review_map_url: map base URLs (optional) - request: implicitly available; current GET params are preserved across views. - scope_only (optional include arg): when truthy, the links carry only the scope parameter instead of the current GET params. Use this on pages whose own query parameters (e.g. back, next, mode) must not leak into the links. The segments are plain navigation links: the active one is marked with aria-current="page" rather than button/toggle semantics. The switcher renders only when at least one gallery or map URL is available. {% endcomment %} {% if public_gallery_url or private_gallery_url or review_gallery_url or public_map_url or private_map_url or review_map_url %}
