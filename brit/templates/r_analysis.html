Analyze BRIT data in R

Download a ready-to-run R file for current waste collection data, or the BRIT-EU code archive for the project's historical case studies.

Current BRIT data

The single R file signs in to BRIT, downloads the collections visible to your account through the extended API, and saves CSV, RDS and provenance files. Its example summary can be changed for your own analysis.

You need R 4.3.3 or newer, internet access and a BRIT account with staff rights or membership in the analysis_api group. Ask the BRIT team for access if your account does not have it.

Download BRIT_Datenanalyse.R

BRIT-EU case studies

The archive contains the original case-study R scripts, the fixed package dependency list, a data manifest and detailed instructions. You can inspect and adapt the analyses locally.

This public archive contains code only. The historical input data are not included while their release and licensing are being resolved. The historical results cannot yet be reproduced from this download alone.

Run the live-data file

  1. Save BRIT_Datenanalyse.R to a folder on your computer.
  2. Open it in RStudio and select Source, or run Rscript BRIT_Datenanalyse.R in that folder.
  3. Enter your BRIT username and password when prompted. The password is not saved in the script or results.
  4. Find the CSV, RDS and provenance files in the new BRIT_Ergebnisse folder.

The first run installs four required R packages in your user library. To change the dataset, edit FILTER near the top of the file; to change the analysis, edit the example at the end. The default scope = "all" includes every collection visible to your account, possibly including private records. Treat exported data according to your access rights.

Use the historical code

Extract the ZIP and read brit_eu/README.md. Once the separately released input files are available, place them as documented in the manifest. In the brit_eu folder, run: 

Rscript --vanilla setup.R
Rscript run.R

The locked package versions support R 4.3.3. These fixed inputs are distinct from the changing BRIT API. Downloading live collections does not recreate the project's historical fact sheets.
