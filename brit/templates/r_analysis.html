Analyze BRIT data in R

Download a ready-to-run R file for current waste collection data, or the BRIT-EU analysis package for the project's historical case studies.

Current BRIT data

The single R file signs in to BRIT, downloads the collections visible to your account through the extended API, and saves CSV, RDS and provenance files. Its example summary can be changed for your own analysis.

You need R 4.3.3 or newer, internet access and a BRIT account with staff rights or membership in the analysis_api group. Ask the BRIT team for access if your account does not have it.

Download BRIT_Datenanalyse.R

BRIT-EU case studies

The archive contains the original case-study R scripts, the fixed package dependency list, the archived historical input data and detailed instructions. The analyses can be reproduced locally, and the statistical methods can be inspected and adapted.

Package version 1.0.5. A smaller code-only archive without the input data is also available for inspecting the scripts.

Download BRIT-EU analysis package (ZIP) Code only, without input data

Run the live-data file

  1. Save BRIT_Datenanalyse.R to a folder on your computer.
  2. Open it in RStudio and select Source, or run Rscript BRIT_Datenanalyse.R in that folder.
  3. Enter your BRIT username and password when prompted. The password is not saved in the script or results.
  4. Find the CSV, RDS and provenance files in the new BRIT_Ergebnisse folder.

The first run installs four required R packages in your user library. To change the dataset, edit FILTER near the top of the file; to change the analysis, edit the example at the end. The default scope = "all" includes every collection visible to your account, possibly including private records. Treat exported data according to your access rights.

Run the historical analyses

Extract the ZIP and open BRIT.Rproj in RStudio. The archive already contains the archived input data; no further downloads are needed.

  1. Open setup.R and select Source. This is needed once; it installs the pinned packages and can take a while the first time.
  2. Open a case script such as scripts/NRW.R and select Source again. Figures are written to results/figures/, and all analysis objects appear in the Environment pane.
  3. To run every case study with input checks, logs and provenance files, enter source("run.R") in the console instead.

From a terminal the same steps are Rscript --vanilla setup.R followed by Rscript run.R (--case=nrw runs a single case). The validated runtime is R 4.3.3 — on Windows install that previous release from CRAN for the pinned package versions. Newer R versions also work: setup.R then installs current package versions, which can shift results slightly. These fixed inputs are distinct from the changing BRIT API. Downloading live collections does not recreate the project's historical fact sheets.
